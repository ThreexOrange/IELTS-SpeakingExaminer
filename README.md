# IELTS-SpeakingExaminer

IELTS Speaking Examiner Skill will rate your score and give you suggestions for improvement.

雅思口语「考官 + 老师」：完整模拟 Part 1、Part 2、Part 3，结束后统一估分、逐句纠错，并保留你的观点给出更自然的表达和完整示范。

## 一句话添加

把下面整句发给支持读取网址的 AI 助手：

> 请读取并按照这个网址的说明安装雅思口语考官与老师 Skill，然后开始 Part 1：https://github.com/ThreexOrange/IELTS-SpeakingExaminer/blob/main/prompt.md

English:

> Read and follow the setup instructions at https://github.com/ThreexOrange/IELTS-SpeakingExaminer/blob/main/prompt.md to install the IELTS examiner-and-teacher skill, then start Part 1.

支持个人 Skill 安装的平台可按自身安装流程保存。普通聊天环境若不支持持久安装，可在当前对话中使用这些指令；这不等于永久安装插件。如果助手无法读取网址，请下载 SKILL.md 并上传到对话。

## 开始练习

可上传自己的题库，也可直接使用 IELTS 风格练习题。告诉助手目标分数是可选的。

- 一次一道英语问题，三个部分结束后再统一评分。
- 复盘用中文说明，也可要求其他语言。
- 给出原句、准确版、自然升级版及具体原因。
- 保留用户观点，示范完整 Part 2 和代表性 Part 1、Part 3 回答。
- 选择最值得改进的三项，进行针对性复练。

## 评分边界

使用 British Council / IELTS 官方公开评分标准进行模拟估分，不代表官方成绩，不保证提分。

仅有文字或语音转写时，不能可靠评估发音、真实停顿或完整流利度，不提供伪精确的完整口语总分。支持原始音频的平台可以基于音频补充评估。平台不能计时时，请自己用手机计时。

官方来源：

- https://takeielts.britishcouncil.org/results/how-is-ielts-assessed
- https://ielts.org/cdn/ielts-guides/ielts-speaking-band-descriptors.pdf

本仓库不包含个人资料、录音、回答、成绩或第三方题库。无需账户密钥，无可执行安装脚本。与 British Council、IELTS 或其合作机构无官方隶属关系。
